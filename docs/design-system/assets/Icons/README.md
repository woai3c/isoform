# Icons

Yansu's own icons, copied from `frontend/src/assets/icons/*.tsx` (default stroke variant). They are single-ink, fixed here at `color-ink` Paper (#202020). In code they draw with `currentColor`.

- Grids: Collapse, Expand, Meeting and Transcript are 20×20. Automation, Chat, Chat bubble, Deliverable, Handoff, Search and Today are 24×24.
- Stroke is 1.25 on the 20px icons and 1.75 on most 24px icons, with round caps and joins.
- Uses: Automation and Handoff are sidebar Library entries; Meeting, Transcript and Handoff lead Recent-list rows; Chat starts a new chat; Search is for the command palette and search fields; Collapse and Expand are the sidebar toggle.
- Everything else uses lucide-react at 14–16px.
