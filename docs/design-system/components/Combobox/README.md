# Combobox

A searchable select built on Popover: a search row, a filtered list with a check on the selected value, keyboard navigation, and virtualised rendering past 50 options.

**Props** `options` (`{value, label}[]`), `value`, `onValueChange`, `placeholder`, optional `allowCustom` (enter a value not in the list), `renderOption`, and portal rendering.

**Style** content is 8px radius, `color-border`, `shadow-card`; the search input is 36px, 13px; empty state is 13px `color-muted`, centred.

Source: `desktop/wails-gui/frontend/src/components/ui/combobox.tsx`. Static rendition.
