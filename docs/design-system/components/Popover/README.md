# Popover

A floating panel (12px radius, `color-border-strong`, 16px padding) anchored to a trigger, for short explanations or small forms.

**Parts** `Popover`, `PopoverTrigger`, `PopoverContent` (portal; fade + zoom 95% + 8px slide by side; sets `--wails-draggable: no-drag`), `PopoverAnchor`.

**Consumer provides** the trigger and content. Answer one question per popover (`Why Yansu suggested this`).

Source: `desktop/wails-gui/frontend/src/components/ui/popover.tsx`. Static rendition.
