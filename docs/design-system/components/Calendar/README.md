# Calendar

A month-view date picker on react-day-picker supporting single, range and multiple selection.

**Style** 36px day cells, 12px numerals, 6px radius; weekday labels 10px `color-muted` at 70%; today gets an inset `color-border` ring; the selected day fills with `color-accent` and `color-panel` text; outside days are `color-muted` at 40%. Caption 13px medium with 28px chevron buttons.

**Consumer provides** react-day-picker props (`mode`, `selected`, `onSelect`, `disabled`…).

Source: `desktop/wails-gui/frontend/src/components/ui/calendar.tsx`. Static rendition.
