# Avatar

A circular avatar showing an image, falling back to up to two uppercase initials on `color-surface-active`.

**Props** `src`, `alt` (default "User avatar"), `fallback` (a name, turned into initials; none → "?"), `size`: xs 20px · sm 24px · md 28px (default) · lg 32px.

**Rule** avatars are chrome, not status: keep them monochrome; never tint them by person or state.

Source: `desktop/wails-gui/frontend/src/components/ui/avatar.tsx`. Static rendition.
