# Switch

A 36×20 Radix toggle for settings that take effect immediately; checked track is `color-ink`, unchecked is ink at 20%.

**Consumer provides** `checked` / `onCheckedChange` and a label that names what turns on (`Independent work`, `Background listening`). The thumb is white unchecked and `color-panel` checked. Focus: 1px `color-accent-2` ring with 2px offset.

**Use** for on/off settings; use `Checkbox` when choosing items in a list.

Source: `desktop/wails-gui/frontend/src/components/ui/switch.tsx`. Static rendition (click to toggle).
