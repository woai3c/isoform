# ScrollArea

A scroll container with a slim custom scrollbar (10px track, ink-at-10% rounded thumb) instead of the OS bar.

**Parts** `ScrollArea`, `ScrollBar` (vertical or horizontal).

**Consumer provides** a sized container (height or max-height) and the content.

Source: `desktop/wails-gui/frontend/src/components/ui/scroll-area.tsx`. Static rendition.
