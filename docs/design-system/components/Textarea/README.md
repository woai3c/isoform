# Textarea

A resizable multi-line field: 72px min height, 12px radius, `color-border` on `color-panel`, 12×14px padding, 14px text.

**Consumer provides** `value` / `onChange` and a placeholder that says what to write (`Tell Yansu what to change about this rule`); placeholders are `color-muted`. Focus: a 2px `color-accent-2` outline at 40% and a matching border.

Source: `desktop/wails-gui/frontend/src/components/ui/textarea.tsx`. Static rendition.
