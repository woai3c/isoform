# Security

Report suspected vulnerabilities privately to **security@isoform.ai**. Do not open a public issue or pull request for a security report.

Include the affected version or commit, your operating system, steps to reproduce the issue, and the possible impact. Attach relevant logs or proof-of-concept code with secrets and personal data removed. Do not test suspected credentials against live services or access data that is not yours.

The maintainers will review the report and respond by email. Please give them time to investigate and prepare a fix before discussing the issue publicly.
