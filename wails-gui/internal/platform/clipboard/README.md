# clipboard

Clipboard package for the Wails GUI desktop application: writes text to the system clipboard on every platform and, on macOS, watches what the user copies.

## Overview

`Write` copies text to the system clipboard. Platform-specific implementations are selected at compile time via Go build tags, so the calling code remains platform-agnostic.

`Watcher` polls the macOS general pasteboard's change counter once a second and reports each new copy once (`wails-gui/clipboard_observer.go` records it as an activity event). The rules, all in `rules.go` and table-tested:

- Nothing but the change counter is read while `Allowed` is false (the switch is off or observing is paused); copies made then count as seen. `Rebaseline` is called the moment the switch or the pause changes, so a pause shorter than a tick still hides what was copied during it.
- A copy whose types include `org.nspasteboard.ConcealedType`, `TransientType` or `AutoGeneratedType` (http://nspasteboard.org) is skipped without reading it.
- `Front` samples the frontmost app (NSWorkspace, no accessibility call) on every tick; `Accept` sees the app at this tick and the previous one and runs before any content is read. The app skips password managers, the sensitive apps in `internal/pii`, Isoform itself and private browser windows there.
- Content is read only when `ContentReadable` is true: before macOS 15.4, or when the user chose Always Allow for Isoform under Paste from Other Apps. From 15.4 the general pasteboard otherwise asks on every programmatic read, and Isoform never shows that alert. Without it only the kind is known.
- `Preview` keeps at most 160 characters, redacted through `pii.RedactText` with every standalone run of 4 or more digits replaced, also when split into groups by spaces, dashes or dots ("482 913"); a link keeps its scheme, host and plain path up to the first token-like segment. No preview at all (`WithholdPreview`) for a single unbroken run (a password, a token, a code), a recovery phrase (12 to 25 short lowercase words) or a text that names a secret (password, passphrase, PIN, recovery or seed phrase, private or API key, one-time or verification code). The app keeps only the kind of a copy made while Safari was in front, since its private windows cannot be recognised by title.
- Isoform's own writes (`Write`, `NoteOwnWrite`, `OwnWrites` around a paste) are never reported as the user's copy.

## Key Components

| File | Build Tag | Description |
|------|-----------|-------------|
| `clipboard.go` | (all) | Package declaration and doc comment |
| `clipboard_darwin.go` | `darwin` | macOS implementation using `pbcopy` |
| `clipboard_linux.go` | `linux` | Linux implementation using `xclip` |
| `clipboard_windows.go` | `windows` | Windows implementation using `clip.exe` |
| `rules.go` | (all) | Copy kinds, skipped types, sensitive sources, secret detection, previews |
| `watch.go` | (all) | `Watcher`, `Copy`, the `Board` interface |
| `board_darwin.go` | `darwin` | `SystemBoard` over `NSPasteboard` (cgo) |
| `board_other.go` | `!darwin` | `SystemBoard` stub; `Supported()` is false |

## API

```go
func Write(text string) error
```

Copies `text` to the system clipboard. Returns a non-nil error if the underlying platform command fails (e.g., the required CLI tool is not installed).

## Platform Details

| Platform | Tool used | Notes |
|----------|-----------|-------|
| macOS | `pbcopy` | Built-in on all macOS versions |
| Linux | `xclip -selection clipboard` | Requires `xclip` to be installed |
| Windows | `cmd /c clip` | Built-in since Windows Vista |

## Dependencies

- **`wails-gui/internal/platform/cmdutil`** — drop-in replacement for `exec.Command` that suppresses the console window on Windows.
- No external Go modules are required; all clipboard access is delegated to OS-native CLI tools.

## Usage

```go
import "wails-gui/internal/platform/clipboard"

if err := clipboard.Write("Hello, world!"); err != nil {
    log.Printf("clipboard write failed: %v", err)
}
```

## Linux Prerequisite

On Linux, `xclip` must be available on `PATH`:

```bash
# Debian / Ubuntu
sudo apt-get install xclip

# Arch
sudo pacman -S xclip
```

## Testing

`rules_test.go` and `watch_test.go` cover the rules and the watcher against a fake `Board`. `Write` and `SystemBoard` depend on a running desktop session, which headless CI lacks, so they are verified by hand.
